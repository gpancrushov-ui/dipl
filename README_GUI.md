# UDP File Manager - Total Commander Style GUI

Полноценный файловый менеджер с графическим интерфейсом в стиле Total Commander для работы с файлами через UDP соединение.

## Особенности

- **Двухпанельный интерфейс**: Левая панель - локальные файлы, правая панель - удалённый сервер
- **Выпадающие списки дисков**: Для обеих панелей с быстрым переключением
- **Поиск UDP соединений**: Автоматическое сканирование сети на наличие серверов
- **Полная поддержка операций**: Копирование, удаление, создание папок, переименование
- **Горячие клавиши**: Как в Total Commander

## Структура проекта

```
udp_file_manager.py  # Полный файл с GUI клиентом и сервером
udp_server.py        # Отдельный сервер (без GUI зависимостей)
README_GUI.md        # Эта документация
```

## Запуск

### Режим сервера (на удалённой машине)

**Вариант 1: Отдельный сервер (рекомендуется для Linux без GUI)**

```bash
python3 udp_server.py
```

Или с указанием порта:

```bash
python3 udp_server.py 5000
```

**Вариант 2: Сервер из полного пакета (требуется tkinter)**

```bash
python3 udp_file_manager.py --server
```

Или с указанием порта:

```bash
python3 udp_file_manager.py --server 5000
```

### Режим клиента (GUI)

```bash
python3 udp_file_manager.py
```

**Примечание**: Для работы GUI требуется установленный Tkinter. На Linux установите пакет `python3-tk`.

## Интерфейс

### Верхняя панель инструментов
- **Local:** Выпадающий список локальных дисков/каталогов
- **⟳** Кнопка обновления левой панели
- **Remote:** Выпадающий список удалённых дисков/каталогов
- **⟳** Кнопка обновления правой панели
- **Индикатор соединения**: Показывает статус подключения (красный/зелёный)

### Левая панель (Local Files)
- Отображает файлы и директории локальной системы
- Навигация двойным кликом или Enter
- Backspace для перехода на уровень вверх

### Правая панель (Remote Files (UDP))
- Отображает файлы и директории удалённого сервера
- Работает только после подключения к серверу
- Навигация аналогична левой панели

### Нижняя строка состояния
- Отображает текущий путь и статус операций

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `Tab` | Переключение между панелями |
| `F5` | Копировать файл (из активной панели в другую) |
| `F7` | Создать новую директорию |
| `F8` | Удалить файл/директорию |
| `F2` | Переименовать файл/директорию |
| `Ctrl+R` | Обновить обе панели |
| `Backspace` | Перейти на уровень вверх |
| `Enter` | Открыть файл/директорию |
| `Double-click` | Открыть файл/директорию |

## Меню

### File
- **Connect to Server...** - Подключение к UDP серверу
- **Disconnect** - Отключение от сервера
- **Exit** - Выход из программы

### Network
- **Scan for Servers...** - Сканирование сети на наличие серверов
- **Manual Connect...** - Ручное подключение к серверу

### Help
- **Keyboard Shortcuts** - Показать горячие клавиши
- **About** - Информация о программе

## Поиск серверов

Функция "Scan for Servers..." автоматически сканирует сеть по следующим адресам:
- 127.0.0.1 (localhost)
- 192.168.1.1
- 192.168.1.10
- 192.168.1.100
- 192.168.1.254

При обнаружении сервера будет показано уведомление со списком найденных IP-адресов.

## Подключение к серверу

1. Запустите сервер на удалённой машине: `python3 udp_file_manager.py --server`
2. Запустите клиент локально: `python3 udp_file_manager.py`
3. Выберите в меню **File → Connect to Server...** или **Network → Manual Connect...**
4. Введите IP-адрес и порт сервера (по умолчанию: 127.0.0.1:5000)
5. Нажмите OK

После успешного подключения:
- Индикатор соединения станет зелёным
- Правая панель заполнится содержимым удалённой файловой системы
- Станет доступен выпадающий список удалённых дисков

## Операции с файлами

### Копирование файлов (F5)
1. Выберите файл в активной панели
2. Нажмите F5
3. Файл будет скопирован в другую панель

**Важно**: Копирование директорий пока не поддерживается

### Создание директории (F7)
1. Перейдите в нужную панель
2. Нажмите F7
3. Введите имя новой директории
4. Директория будет создана в текущем каталоге

### Удаление файлов (F8)
1. Выберите файл или директорию
2. Нажмите F8
3. Подтвердите удаление

### Переименование (F2)
1. Выберите файл или директорию
2. Нажмите F2
3. Введите новое имя

## Протокол обмена

Программа использует бинарный протокол поверх UDP:

```
Запрос:
[CMD: 1 byte][Data Length: 4 bytes][Data: N bytes]

Ответ:
[Status: 1 byte][Data Length: 4 bytes][Data: N bytes]
```

### Команды
- `1` - LIST_DIR (список директории)
- `2` - GET_FILE (скачать файл)
- `3` - PUT_FILE (загрузить файл)
- `4` - DELETE (удалить)
- `5` - MKDIR (создать директорию)
- `6` - RENAME (переименовать)
- `7` - GET_DRIVES (получить список дисков)
- `8` - CHANGE_DIR (сменить директорию)

### Коды ответов
- `100` - OK (успех)
- `101` - ERROR (ошибка)
- `102` - DATA (данные)
