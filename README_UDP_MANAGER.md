# UDP Файловый Менеджер в стиле Total Commander

Двухпанельный файловый менеджер для работы через UDP соединение.

## Компоненты

### 1. Сервер (server.py)
Запускается на удалённой машине, предоставляет доступ к файловой системе.

```bash
python3 server.py
```

**Порт по умолчанию:** 5000

### 2. Клиент (client.py)
Консольный клиент с интерфейсом в стиле Total Commander (curses).

```bash
python3 client.py <IP_адрес>:<порт>
# Пример:
python3 client.py 192.168.1.100:5000
```

## Возможности

### Интерфейс
- **Левая панель** - локальная файловая система
- **Правая панель** - удалённый сервер через UDP
- Двухпанельный режим с переключением по Tab
- Цветовая схема как в Total Commander

### Горячие клавиши
| Клавиша | Действие |
|---------|----------|
| `Tab` | Переключение между панелями |
| `↑/↓` | Навигация по файлам |
| `Enter` | Открыть файл/директорию |
| `Backspace` | Перейти вверх |
| `F5` | Копировать файл |
| `F7` | Создать директорию |
| `F8` | Удалить файл |
| `F2` | Переименовать |
| `Ctrl+R` | Обновить обе панели |
| `Q` | Выход |

### Протокол
- **Команды:** list_dir, get_file, put_file, delete, mkdir, rename, get_drives
- **Транспорт:** UDP
- **Кодировка:** JSON + Base64 для бинарных данных

## Проверка соединения

```bash
# Запустить сервер
python3 server.py

# В другом терминале проверить соединение
python3 -c "
import socket, json
sock = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
sock.settimeout(2.0)
sock.sendto(json.dumps({'command': 'list_dir', 'path': '.'}).encode(), ('127.0.0.1', 5000))
data, _ = sock.recvfrom(4096)
print('Сервер отвечает:', json.loads(data.decode()))
"
```

## Требования
- Python 3.6+
- Для клиента: curses (встроен в Linux/Mac, для Windows: `pip install windows-curses`)

## Примечания для Windows
1. Ошибка `[WinError 10054]` означает, что сервер не запущен или недоступен
2. Проверьте брандмауэр - порт 5000 должен быть открыт
3. Для GUI версии требуется Tkinter: `pip install tk`
