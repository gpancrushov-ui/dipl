# UDP File Manager в стиле Total Commander

Двухпанельный файловый менеджер для работы через Ethernet с использованием UDP протокола. Интерфейс выполнен в классическом стиле Total Commander.

## Компоненты

### Сервер (server.py)
Серверная часть, которая предоставляет доступ к файловой системе через UDP.

**Запуск:**
```bash
python3 server.py
```

По умолчанию сервер слушает на порту 5000.

### Клиент (client.py)
Клиентская часть с текстовым интерфейсом в стиле Total Commander.

**Запуск:**
```bash
python3 client.py [сервер:порт]
```

Примеры:
```bash
# Подключение к локальному серверу
python3 client.py

# Подключение к удаленному серверу
python3 client.py 192.168.1.100:5000
```

## Возможности

### Навигация
- **Tab** - Переключение между панелями
- **↑/↓ или K/J** - Перемещение по списку файлов
- **Enter или → или L** - Войти в директорию / Открыть файл
- **← или H** - Вверх по дереву директорий
- **Home/End** - Переход в начало/конец списка

### Операции с файлами
- **F5 или C** - Копировать файл между панелями
- **F6 или M** - Переместить файл
- **F7 или N** - Создать новую директорию
- **F8 или D** - Удалить файл/директорию
- **F9** - Меню (смена сервера)
- **Q или Escape** - Выход

### Особенности интерфейса
- Две независимые панели (локальная и удаленная)
- Цветовое выделение директорий (желтый) и файлов (белый)
- Активная панель подсвечивается синим
- Статусная строка с текущими путями
- Строка помощи с горячими клавишами
- Отображение размеров файлов

## Протокол

Коммуникация происходит через UDP с использованием JSON:

### Команды клиента:
- `list_dir` - Получить список файлов
- `get_file` - Скачать файл
- `put_file` - Загрузить файл
- `delete` - Удалить файл/директорию
- `mkdir` - Создать директорию
- `rename` - Переименовать
- `get_info` - Получить информацию о файле

### Ответы сервера:
- `status: ok/error` - Статус выполнения
- `items` - Список файлов и директорий
- `chunk` - Чанк данных файла (base64)

## Требования

- Python 3.6+
- Стандартные библиотеки: socket, json, curses, pathlib

## Пример использования

1. Запустите сервер на удаленной машине:
```bash
python3 server.py
```

2. Запустите клиент на локальной машине:
```bash
python3 client.py 192.168.1.100:5000
```

3. Используйте клавиши для навигации и управления файлами

## Примечания

- UDP не гарантирует доставку пакетов, поэтому для больших файлов используется разбиение на чанки
- Для надежной передачи в реальных условиях рекомендуется добавить механизм подтверждения получения пакетов
- Максимальный размер UDP пакета ограничен ~65KB, файлы передаются частями по 1400 байт
